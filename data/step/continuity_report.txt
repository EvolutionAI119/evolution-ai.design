[Conclusion]
  Body connection pairs: 3 (body<->front_bumper, body<->rear_bumper, body<->wheel)
  G0 pass (<0.1mm): 0/3
  G1 pass (<1deg):   0/3

  Root cause: All 14 parts are constructed as INDEPENDENT NURBS surfaces.
  No boundary curves are shared between adjacent parts. Each part's boundary
  is determined by its own control point grid, which does not match the
  neighboring part's boundary geometry.

  Body<->bumper: 21-24mm gap (body section profile vs bumper rectangular edge)
  Bumper<->lights/grille: 120-215mm gap (parts positioned in x but boundaries
    do not align with cutout/recess boundaries)

  Notes:
  - Wheels/mirrors are separate parts (design clearance), not rated.
  - Headlights/taillights embed into bumper recesses, small gaps expected
    (assembly tolerance), but current 120-215mm gaps are too large.

==============================================================================
[Improvement Recommendations]
==============================================================================
1. G0 continuity (positional): Share boundary curves between adjacent parts.
   a) Body<->bumper: Extract body u=0/u=1 boundary lower section (z in
      [gc, gc+0.5]) and use it as the bumper's top edge (v=1) control points.
   b) Bumper<->grille: Use grille boundary as the bumper recess boundary
      (same control points for matching edges).
   c) Bumper<->headlight: Cut a hole in the bumper matching headlight outline.

2. G1 continuity (tangential): Match control points across shared boundary.
   - For each shared edge, ensure the 2 rows of control points on either side
     are collinear with the boundary control points (3-point collinearity).
   - This makes surface normals match at the boundary (G1).

3. Implementation approach:
   - Build a topological graph of shared edges first.
   - Construct shared boundary B-spline curves once.
   - Each part's NURBS surface reuses these shared curves as boundary rows.
   - Adjust interior control points for G1 (collinearity constraint).

4. Priority: body<->bumper (21mm -> 0mm) first, then bumper<->grille/lights.
