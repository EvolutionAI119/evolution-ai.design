# Framework Map

> Author: Quantum Swordsman

The frameworks in this book are not a flat list but a nested chain: each layer legislates for the one below, and each layer below bears witness for the one above. Before reading any chapter, locate it on the chain.

## 1. The Nested Chain

**Epistemology → Organization → System → Dynamics**

| Layer | Frameworks | Position on the Chain |
|---|---|---|
| Epistemology | Open Complex Giant System (OCGS), Metasynthesis | Answers "what the object is"; sets the epistemic premise for the whole book |
| Organization | General Design Department · three systems, six roles, three rhythms | Answers "who does the work"; turns epistemology into organizational form |
| System | Five-layer architecture L1–L5, contract-first | Answers "where complexity lives"; turns organizational intent into system structure |
| Dynamics | Fast/slow variables, closed loops, seven theses | Answers "how the system grows"; lets structure evolve over time |

## 2. What Each Framework Does

**Open Complex Giant System (OCGS)** —— Duty: characterize styling development as an open complex giant system, not a reducible machine. Answers: why does reductionist waterfall governance fail here? See Ch. 2.

**Metasynthesis (from qualitative to quantitative)** —— Duty: converge qualitative experience into quantitative conclusions through the triangular loop of expert, machine, and knowledge systems. Answers: how does expert judgment become reproducible numbers? See Ch. 3.

**General Design Department · Three Systems** —— Duty: a human–machine hall for deliberation — machines supply candidates and evidence; humans retain judgment and accountability. Answers: how much does AI do, how much do humans do, and who carries the responsibility? See Ch. 15.

**Six Roles · Three Rhythms** —— Duty: the staffing and time orchestration of an AI-native team, closed by one acceptance line. Answers: which roles divide the labor, and on what rhythms does the team run? See Ch. 17.

**Five-Layer Architecture (L1–L5)** —— Duty: the web layer only orchestrates; the algorithm core installs, tests, and swaps independently. Answers: which layer hosts which kind of complexity, and how are cross-layer calls forbidden? See Ch. 4.

**Contract-First** —— Duty: endpoints, tables, and state machines are frozen before implementation; 100% field alignment is a hard constraint. Answers: who decides the interface, when is it frozen, and how is drift prevented? See Ch. 6.

**Fast/Slow Variables and the Seven Theses** —— Duty: grasp the order parameters, let fast variables trial-and-error, and use closed loops to sediment experience into structure. Answers: how does the system keep evolving without losing control? See Ch. 18.
