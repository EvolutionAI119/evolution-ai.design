## 等分排布公式

n 个卡片、间距 g、区域高 CH：

```
card_h = (CH − (n−1) × g) / n
card_y(i) = Y0 + i × (card_h + g)
```

常用 g：六层架构 0.08；五要点 0.09；四工具 0.12；安全卡片区 0.18–0.2。

## 文字框高度

- 行距系数 1.2，单行最小高 = size × 1.2 / 72 英寸
- 卡片内文字：x 内缩 0.16–0.2；标题与正文间距 0.06–0.1
- 先按 (卡片宽 − 内缩×2) 与字号估算每行字符容量（中文约 宽/(字号/72)，英文约 2×中文容量），超宽必须折行并按折行数预留高度
- 描述文案尽量收到一行；信息不足时缩短文案，不要靠溢出
