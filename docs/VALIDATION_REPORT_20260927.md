## 3. 一站式自检（test_all.py，5 模块）

### 3.1 整车建模（默认参数）

- **10 部件 / 176 顶点 / 316 面**：body、hood、roof、windshield、rear_window 各 8 顶点 12 面；4 轮各 34 顶点 64 面；
- 自定义参数整车（L=4.9 W=1.92 H=1.5 roof_arc=0.55）同样 176/316；
- 参数校验：越界参数被正确捕获。

### 3.2 曲面质量评估

| 参考曲面 | 等级 | G2 比率 | 反射线 | G0/G1/G2 计数 | 最大跳变 |
|---|---|---:|---:|---|---:|
| 球面 | D | 0.199 | 0.291 | 722 / 212 / 144 | 80.56° |
| 车身侧视（49×25 单侧网格） | C | 0.855 | 0.158 | 2304 / 1993 / 1970 | 180.0° |

解读：车身截面网格在角度连续性上已接近 A 级门槛，但曲率均匀度（反射线）仍低于 0.7，综合为 C——是造型收敛过程中的真实中间态。

### 3.3 AI 模拟退火优化（80 步）

| 对象 | 等级变化 | G2 变化 | 反射线变化 |
|---|---|---|---|
| 球面 | D → D | 144 → 144 | 0.291 → 0.291 |
| 车身侧视 | C → C | 1970 → 1970 | 0.158 → 0.158 |
| 噪声平面（120 步） | D → D | 478 → 274 | 0.330 → 0.339 |

结论与工程指引一致：连续、硬点主导的面板上光顺空间有限；可测改善出现在受扰动曲面，故**局部 A 级光顺应在硬点冻结后进行**。

### 3.4 分镜生成与渲染

- car_promotion：7 镜 / 90s；tech_demo：5 镜 / 90s；minimal_showcase：2 镜 / 90s；
- 自定义（投资人受众）按时长等比缩放正常；
- Markdown 1968 字符、HTML 9471 字符渲染成功。

## 4. 贝叶斯优化收敛验证

在受控一维目标 `f(x) = −(x−0.5)²`（最优 0，x=0.5）上运行 15 轮 suggest–observe：

| 采集函数 | best x | best score | 进入 −0.01 带 |
|---|---:|---:|---|
| EI | 0.5000 | −0.00000 | ✅ |
| UCB | 0.4999 | −0.00000 | ✅ |

证据含义：随机填充 → GP 拟合 → 采集寻优的完整路径正确工作，两种采集均能在小预算内定位到已知最优区域。该实验用于**引擎正确性**验证，不宣称对外部调优库的样本效率优势。

## 5. 本轮缺陷修复与验证
