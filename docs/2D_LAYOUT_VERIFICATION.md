## 1. 交付物与架构约束

| 交付项 | 落点 |
|---|---|
| 2D 侧视布置图渲染 | [Car2D.vue](../src/components/Car2D.vue)（`<g class="interior-layer">`） |
| 2D 横断面右视图渲染 | [CarSection2D.vue](../src/components/CarSection2D.vue)（Designer 右视口 `A-A` 页签） |
| 3D 内饰网格 | [carInterior.js](../src/utils/carInterior.js) → [Car3D.vue](../src/components/Car3D.vue) `addInteriorSeats`（座椅 `createSeatRow` + 其余内饰件 `createInteriorTrim`） |
| 布置真源（几何 + 定位 + 度量） | [carInteriorLayout.js](../src/utils/carInteriorLayout.js)（`deriveInteriorLayout` / `deriveSectionLayout` / `deriveInteriorTrim`） |
| 2D 投影（正/反变换） | [car2dProjection.js](../src/utils/car2dProjection.js)（`createSideViewProjection` / `createFrontViewProjection`） |
| 自动化验证 | [carInteriorLayout.spec.js](../src/tests/carInteriorLayout.spec.js)（153 项） |

**架构约束（对齐的前提）**：2D 与 3D **不得各自推导坐标**。所有内饰锚点由 `deriveInteriorLayout(P)` 输出（单位米，P 坐标系：X+ 车头、Y+ 向上、Z+ 副驾侧、Y=0 地面）。2D 仅做一次「镜像 + 翻转」的像素换算（`createSideViewProjection` / `createFrontViewProjection`），3D 直接使用米值建网格。任何消费端另立数值都视为违规。

**两个视图的投影关系**：侧视为 X-Y（车头朝左），横断面为 Z-Y（车头方向上看去，副驾侧 Z+ 在画面左、驾驶侧 Z- 在画面右）。两者 Y 值逐值同源（同一 `deriveInteriorLayout`），X 方向在断面中不参与投影——这正是中控台在侧视里被坐垫遮挡的根因。Car2D 中过前排 H 点的 `A-A` 剖切线与 CarSection2D 的取图平面为同一 X。

## 2. 多级检查机制

| 级别 | 名称 | 内容 | 执行方式 | 结果 |
|---|---|---|---|---|
| L1 | 静态契约检查 | 内饰几何常量唯一性、排/座数与 `carProfile` schema 一致、纯函数可重入 | `npx vitest run` | 通过 |
| L2 | 2D 布置图合规检查 | 所有元素落在车身包络内、同类元素互不穿模、标注齐全 | 断言 + 目视 | 通过 |
| L2b | 横断面（右视图）合规检查 | 中控台与座椅横向净距 ≥ 20 mm、座椅不越门内壁（留 50 mm）、中控台宽 200 mm、断面 Y 与侧视逐值同源、3D 座椅 Z 包络一致 | 断言（D 组）+ 目视 | 通过 |
| L2c | 纵向基准（门洞匹配）检查 | 前排坐垫整块落在前门洞内、坐垫前缘 → 门洞前缘 ≥ 160 mm、靠背不侵入 B 柱、后排 H 点落在后门洞中段、相邻排距 ≥ 580 mm | 断言（E 组，6 车型全量） | 通过 |
| L2d | 剩余内饰件合规检查 | 地毯/顶棚/中央通道/门板内饰/扶手/安全带固定点全部落在座舱内表面以内，且与座椅、仪表台、中控台无重叠 | 断言（F 组，6 车型全量） | 通过 |
| L2e | 滑轨全行程 + 运动件扫掠检查 | 滑轨有效行程端点余量 ≥ 10 mm（G 组）；调角器限位角 / 遮阳板接触角 / 扶手盖 75° 全行程无穿透（运动学组，6 车型全量） | 断言（G 组 + carInteriorKinematics.spec.js） | 通过 |
| L3 | 人机工程验证 | 头部余量、坐垫-地板、H 点→仪表板、膝部余量、腿部空间、中控/门板可达性 | 阈值断言（6 车型全量） | 通过 |
| L4 | 3D↔2D 坐标对齐校验 | 同源取数零偏移、AABB 包络一致性、2D 像素可反解回 3D 米 | 数值断言 | 通过 |
| L5 | 交叉审核 + 实机目视 | 6 车型 2D 视图实机渲染目视（真实 UI，非 mock） | 浏览器实机 | 通过 |

L1~L4 与 L2b 为**可重跑**的自动化闸门；L5 为人工复核，每次改动后重做。L2b 之所以单列，是因为侧视图为 X-Y 投影、不含 Z 维度，中控台与座椅的横向关系在侧视中不可判定，只能由横断面（Z-Y）证明。

## 3. 检查清单

### 3.1 2D 布置图合规性（A 组）

| 编号 | 检查项 | 判据 | 实现/证据 |
|---|---|---|---|
| A-01 | 四类零部件齐备 | 侧视图必须同时出现 IP、CONSOLE、DOOR PANEL、SEATS | `interior2d` 输出 7 个图元组 |
| A-02 | 座椅组成完整 | 每排 = 坐垫矩形 + 靠背多边形 + 头枕多边形 | `seatSideEnvelope` |

| A-04 | 排数/座数 | 排数 = `seatRows`；每排座数 = `seatRowCounts` | 断言全 6 车型 |
| A-05 | 元素不越界 | 座椅/仪表台/中控/门板 X∈(rearX, frontX)，Y∈(0, roofTopY) | 断言 AABB |
| A-06 | 不穿模 | 坐垫前缘 ≤ 仪表板面；中控台仅与仪表台重叠 100mm | 断言 |
| A-07 | 地板可视化 | 地板线高于车身底板且低于腰带线 | `deriveFloorY` + 断言 |

| A-09 | 图元层级 | 背景带（门板/地板/地毯/顶棚）→ 仪表台 → 座椅 → 安全带固定点 → 中控 → 后排通道 → 方向盘 | 模板 DOM 顺序 |
| A-10 | 无空排/回落 | 越界排号返回 `null`，不得回落到相邻排 | 断言 sport 第 2 排、sedan 第 5 排 |

### 3.3 3D↔2D 坐标对齐校验（C 组）

| 编号 | 检查项 | 判据 |
|---|---|---|
| C-01 | 原点一致 | 3D 座椅 `position.x/y` 与 2D H 点坐标**逐位相等**（`toBe`，非近似） |
| C-02 | 横向分布一致 | 3D `position.z` = `rowSeatLayout.centers[i]`（2D 同源算法） |
| C-03 | 几何包络一致 | 3D 坐垫/靠背/头枕 AABB ⊂ 2D 侧视包络，容差 **±20 mm**（= 单面倒角 12 mm + 余量） |
| C-04 | 投影可逆 | `fromX(toX(x))=x`、`fromY(toY(y))=y`，误差 < 1e-9 m |
| C-05 | 比例一致 | 屏幕宽高 = 米值 × `pxPerM`，与像素密度无关（不同 `pxPerM` 断言） |
| C-06 | 方向盘 | 2D 圆心/半径 = 3D 圆环 position/radius（同一 `steerWheel` 字段） |
| C-07 | 常量唯一 | 2D 包络尺寸 = `INTERIOR_GEOM`（坐垫深 500 / 厚 120 …），无第二套数值 |

**容差口径说明**：C-01/C-02 为**零容差**（同一数值对象直接赋值）；C-03 允许 ±20 mm 仅用于吸收挤出几何倒角（12 mm）与浮点，不是坐标偏移；任何超出该容差的偏差即判为对齐失败。

### 3.4 横断面（右视图）合规性（D 组）

取图平面：Z=0 纵向对称面所截的 Z-Y 断面，X 取**前排 H 点**（与 [Car2D.vue](../src/components/Car2D.vue) 中的 `A-A` 剖切线同一 X）。画面左侧为副驾侧（Z+），右侧为驾驶侧（Z−）。

| 编号 | 检查项 | 判据 | 实现/证据 |
|---|---|---|---|
| D-01 | 中控台 ↔ 座椅横向净距 | 每座内缘 → 中控台外缘 ≥ **20 mm**（`seatToConsoleClearance`）；实测最紧 85 mm | `deriveSectionLayout.metrics.seatToConsoleGap`，逐座显式判定，重叠即 `throw` |
| D-02 | 座椅不越门内壁 | 座椅外缘 → 门板内表面 ≥ **50 mm**（`seatToWallClearance`），且任一 `abs(z) ≤ halfInterior` | `metrics.seatToTrimGap` + `halfInterior` |
| D-03 | 中控台宽度同源 | `console.z1 − console.z0` = `INTERIOR_GEOM.consoleWidth` = **200 mm**，以 Z=0 对称 | 零容差 `toBe` |
| D-04 | 断面 Y 与侧视逐值同源 | 断面 `floorY / bodyBottomY / beltLineY / roofTopY / cushionY0 / cushionY1 / backTopY / headrestTopY` 与 `deriveInteriorLayout` 对应字段**逐位相等**（`toBe`） | 断言 6 车型 |
| D-05 | 3D 座椅 Z 包络一致 | 3D 网格 `z ∈ [z0, z1]`，容差 **±20 mm**（口径同 C-03） | `rowSeatLayout.centers[i] ± width/2` |
| D-06 | Z 投影可反解 | `fromX(toX(z)) = z`，误差 < 1e-9 m；`rect(z0, z1, …).w` = `consoleWidth × pxPerM` | `toBeCloseTo(z, 9)` |
| D-07 | 三座长排连续 | 三座中心间距 = 单座宽（无虚伪缝），外缘仍留 50 mm | 断言相邻中心差 = `width` |

**为什么必须有 D 组**：A 组第 A-06 条只判「坐垫前缘 ≤ 仪表板面」这类 X-Y 关系，横向干涉完全盲区——旧 `rowSeatLayout` 双座净距仅约 126 mm，小于 200 mm 中控台宽度，侧视图一路「通过」而实际几何已经相撞（FIX-07）。

### 3.5 座椅纵向基准（门洞匹配）检查（E 组）

**根因**：旧版以前排「方向盘中心后 520 mm」定 H 点，而方向盘 X 又由前风挡几何中点推导 → 座椅随前舱几何被推到前门洞前缘（sedan 坐垫前缘 931 mm vs 门洞前缘 971 mm，仅 40 mm），乘员无落脚区。正确顺序是**先由门洞定义乘员落脚区 / 后排入口，再由座椅反推方向盘**。

| 编号 | 检查项 | 判据 | 实现/证据 |
|---|---|---|---|
| E-01 | 前排 H 点锚点 | `H1.x = 前门洞前缘 − (坐垫深 500 − 前缩 60) − 160`，并以「仪表台最小进深 + 膝部余量 30 mm」封顶 | `deriveFrontRowX`，断言 `rows[0].x === deriveFrontRowX(P)` |
| E-02 | 上下车通行余量 | 坐垫前缘 → 前门洞前缘 ≥ **160 mm**；坐垫后端仍在门洞内（`x − 60 > midSeamX`） | `metrics.entryClearance` |
| E-03 | 前排靠背 ↔ B 柱 | 靠背本体后缘（含后倾）→ B 柱前缘 ≥ **20 mm** | `metrics.bPillarGap`（实测最紧 SUV 25 mm） |
| E-04 | 方向盘由 H 点派生 | `steerWheel.x = H1.x + 520`；不得反向定义座椅 | 零容差断言 |
| E-05 | 靠背倾角按车型解析 | sedan 0.36 / suv 0.34 / coupe 0.33 / sport 0.30 / mpv 0.38 / pickup 0.38 rad；**2D 包络与 3D 枢轴同值** | `seatBackLean`，断言 `pivot.rotation.z` 相等 |
| E-06 | 后排门洞匹配 | 四门车 `H2.x` 落在后门洞内，后排坐垫前缘 → B 柱后缘 ≥ **60 mm**；双门车按排距后移、皮卡贴驾驶室后壁 | `metrics.rearCushionToBPillar` + 断言 |
| E-07 | 最小排距 | 相邻排 H 点间距 ≥ **580 mm**（靠背厚 130 + 后排最小腿部空间 450） | `minRowPitch` |

## 4. 交叉审核流程

```
① 提交自检（开发）          → npx vitest run 全绿；2D/3D 目视截图
② 同源核对（审核 A）        → 抽查任一锚点：2D DOM 属性反解 ↔ deriveInteriorLayout ↔ 3D 网格坐标
                               三者必须落同一数值（见 C-01/C-04）
②b 断面核对（审核 A）       → Designer 右视口切到 A-A 页签，核对中控台位于两座之间、
                               净距虚线与读数（CONSOLE / CLEAR / SEAT W / IW）一致（见 D-01~D-03）
②c 纵向核对（审核 A）       → 侧视图中坐垫矩形须整块落在前门洞（门洞两端由外观
                               deriveDoorLayout 同源分缝线指示），坐垫前缘到门洞前缘留 ≥160 mm，
                               后排 H 点落在后门洞中段（见 E-01~E-07）
②d 内饰件核对（审核 B）     → 地毯/顶棚/门板内饰/安全带固定点与座椅、中控台的相对位置
```
