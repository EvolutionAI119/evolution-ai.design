1 · 设计说明

1.1 IP / CONSOLE 区域

造型细节与功能模块集成。仪表台（IP）按「上体软包 / 下体硬塑」两段式分型（分型线见各车 IP 竖向带 55% 高度），上体为搪塑软质表皮、下体为硬质注塑骨架件；四个功能分区沿 IP 后面板一字排开——驾驶信息区（组合仪表居方向盘正前方，上沿贴 IP 顶，保证方向盘轮缘不遮挡视认）、信息娱乐区（12 英寸级中控屏座舱中线布置，悬浮式安装探出 IP 面 60 mm：缩短驾驶员手伸距 40~70 mm，同时消除厚重视觉体量）、空调出风区（中央风口×2 夹屏两侧，侧风口×2 贴近左右门内壁指向侧窗除霜）、副驾储物区（手套箱 + IP 顶面副驾气囊隐形盖板，盖板上沿与 IP 顶齐平）。

中控台面功能带按操作频次自前向后排序：无线充电托盘（目视可取）→ 换挡模块（右手自然落点，全坐姿手伸距实测 430~755 mm，均满足分级目标）→ 双杯托（Z 向并排沉台，低于台面 50 mm，行驶中取放不碰换挡）→ 扶手盖（铰链居后、前掀开启，与既有扶手盖运动学扫掠模型同一锚点，开启 75° 全程与 IP/顶棚零干涉已闭环）。两排及以上车型中控台尾端集成后排出风口。

人机工程布局全部锚定既有 H 点 / IP / 方向盘真源，未引入第二套座舱数值；手伸距、组合仪表视认高度等指标由真源实时解算并进入单元测试断言（见 §4）。

材质工艺匹配延续整车深色内饰体系：IP 上体搪塑 PVC 表皮 + PU 发泡，中控饰板 PC/ABS + IMD 钢琴黑，显示屏 / 组合仪表黑晶钢化玻璃盖板，出风口 PA66+GF30 缎面金属饰圈，扶手盖 TPO 包覆同色缝线——与座椅材质预设（executive / standard / sport）共享色彩与光泽区间（详见 §3 材质规格表）。

1.2 前行李舱（frunk）

前行李舱布置于前轴前方、机盖之下的储物井（轿跑/跑车平台前舱无动力总成侵占），舱体前壁距车头外板 120 mm 作为碰撞溃缩与机盖锁机构空间，后界整体避让前轮拱「满舵转向 + 悬架跳动」合成包络 + 50 mm（图 4 红虚线）。舱内含 PET 针刺地毯地板、PP 蜂窝板四周衬里、右侧壁 LED 舱灯、前缘中心机盖锁扣、地板前部系留锚钩×2。六车型中 5 款具备几何条件（108~170 L）；SUV 因越野轮拱包络（跳动 80 mm + 满舵 34°）占满前舱，几何上无前行李舱——与工程实情一致（前舱为动力/底盘舱），本方案如实标注「无」而非虚设。

1.3 后行李舱（开启状态）

按车身拓扑分三类：① 封闭式行李舱（sedan/coupe/sport）：舱体覆盖甲板盖范围，含地板地毯、两侧围衬板、前壁（座椅骨架）衬板、尾盖内板、装载门槛护板（304 拉丝不锈钢/PP+GF）；② 旅行式货舱（suv/mpv）：舱体自车尾延伸至末排靠背后缘，后轮拱侵入侧壁处以 PP 饰盒包覆并输出「拱间净宽」指标（SUV 实测 1326 mm），容积按 VDA 惯例计至遮物帘/窗线，盖板以上净空另注不计容积；③ 皮卡货箱：开放舱衬里（地板 + 前壁 + 侧壁 + 尾门内板），栏板顶为舱口。

三类拓扑共用同一套功能件：系留锚钩×4（地板四角，单点静载设计值 ≥400 N）、储物网锚点×2（侧壁高 350 mm）、LED 舱灯（右侧壁距地板 350 mm，舱内照度设计值 ≥50 lux）、锁扣 + 荧光应急拉手（舱口下缘中心，防误关被困）、地板下储物井（地板与车身底板净高 ≥200 mm 时自动开设，收纳随车工具/补胎套件）。耐磨防刮体系：舱壁 PP 蜂窝板复合 PET 毡、地板 PET 针刺地毯 + TPE 防滑背胶、门槛金属护板防踢刮（§3）。

4.1 设计要求类（工程落地阶段验证，非几何断言）

  • 系留锚钩单点静载 ≥400 N，四点布置呈矩形（前后间距 ≥舱长 60%）；
  • 舱内 LED 照度 ≥50 lux（地板面），开关与舱盖开关联动 + 30 s 延时熄灭；
  • 尾盖/机盖应急拉手荧光可视（黑暗中可视距离 ≥1 m），拉力 ≤50 N 可解锁；
  • 门槛护板 50 kg 行李箱拖拽 100 次无可见划痕（实验室 Taber/落球复验）；
  • 扶手盖开合疲劳 ≥5 万次；IP 表皮低温 -30℃ 无开裂（随整车环境舱试验）。

6 · 工程落地输入条件与开口问题

  • 封闭式行李舱容积为「甲板覆盖段」保守口径（sedan 189 / coupe 237 / sport 259 L）：舱体前延至后排座椅骨架下方（实车 E 级 ≈540 L）需平台部提供后悬架/油箱（电池包）布置输入后冻结，本方案已在数据层预留 trunkStartX → lastBackRearX 扩展位；
  • SUV 无前行李舱：前轮拱跳动+满舵包络占满前舱（几何断言锁定），前舱按动力/底盘舱处理；
  • 尾盖/机盖开闭机构未纳入本次：铰链、气弹簧、锁体仅作位置规划（图 2/3/4 中盖内板为全开示意），舱内内饰与之接口（锁扣/拉手位置）已冻结；
  • MPV 手伸距为六车型上限（屏 827 / 换挡 755 mm）：建议量产配置中控屏向驾驶员侧倾角 8°，换挡模块备选怀挡（IP 下沿集成），待下一轮 HMI 评审冻结。

7 · 结论

IP/CONSOLE 区域完成「四分区 + 功能带」全模块参数化布置，前后行李舱完成三拓扑（封闭式/旅行式/货箱）开启状态全件内饰布置；全部坐标源自单一真源链（deriveCarProfile → deriveInteriorLayout → deriveIpConsoleLayout / deriveLuggageLayout），3D 网格（createIpConsole / createLuggageTrim）与真源逐值一致，六车型 55 项专项断言 + 全量 765 项测试全过。方案可直接进入工程落地阶段，开口问题 §6 已列明输入条件。
