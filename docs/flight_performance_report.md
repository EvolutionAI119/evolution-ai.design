## 02 反重力驱动技术理论推导

前一章确认了数据可信，本章回答更深一层的问题：**这组数字从哪里来**。反重力飞控的全部指标 —— 有效重力、场升力份额、悬停功率、续航倍数、峰值因子、姿态包络与延迟 —— 均由**三个受界假设**（度规屏蔽系数 η_e、惯性配比 η_cdm、盘载荷基准）出发，经经典力学、动量理论与控制论**解析推导**得出，不含任何拟合黑箱。以下六节按因果链顺序展开，为第 03~07 章的五项目标实测提供理论根基。

### 2.1 度规屏蔽假设与有效重力（科幻受界）

暗能量以负压态（状态方程 w = −1）存在，其工程化类比是：在车体邻域建立局部度规曲率，对**引力测度**产生屏蔽。关键取舍在等效原理的「单向近似」—— 度规效应只作用于引力测度，**不改变惯性质量**：机动与姿态响应仍需真实推力，因此所有动力学行为保持物理自洽，不会出现「惯性消失」的失控场景。屏蔽系数受界 η_e∈[0, 0.3]（超出则屏蔽层边界梯度失稳），0.35 为屏蔽耦合上限：

```
g_eff(η_e) = g·(1 − 0.35·η_e)    （η_e∈[0,0.3] → g_eff ∈ [0.895g, g]）
T/W = g / g_eff = 1/(1 − 0.35·η_e) ≥ 1    （悬浮充要条件；η_e = 0 时恰为 1.0）
```

### 2.2 悬浮充要条件与场-风扇分工

垂直方向力平衡定义了系统的第一分工：**场升力承担份额，风扇保留权限**。定义场份额 s ≡ L_field/W_eff，其线性响应形式 s = 2.6·η_e + 1.8·η_cdm 中，η_e 主导场升力生成（负压梯度的一阶响应），η_cdm 贡献惯性屏蔽下的等效卸载。钳位 s ≤ 0.75 出自控制论而非能量考量：**场是「慢通道」（度规建立约 30 ms 量级），姿态带宽必须由风扇「快通道」承担** —— 保留 ≥25% 推力做差动，正是 ±2° 姿态包络的存在前提。

### 2.3 诱导功率 1.5 次方律与能耗分解

节能的数学核心在动量理论：悬停诱导功率 P ∝ T^1.5/√(2ρA)（理想盘面，桨叶品质因数并入基准）。**推力降为 (1−s) 倍时，功率按 (1−s)^1.5 缩减** —— 这一半立方律使「场顶格 75%」的收益被放大：s = 0.75 时风扇功率只剩基准的 0.25^1.5 = 12.5%。场维持功率是另一类项：度规曲率的保持是对几何的支付而非对外做功，仅承担相干性耗散 12 W/kg × s：

```
P_fan(s) = P_base·(1−s)^1.5    （动量理论半立方律，s=0.75 → ×0.125）
P_field = 12 W/kg · m · s    （度规维持 = 相干性耗散，非推进做功）
P_base(m) = 55·(m/t)^1.2 kW    （同量级高效升力风扇盘载荷基准，1.2 为雷诺数/桨尖损失经验律）
P_悬停 = P_fan + P_field    （sedan：98.88×0.125 + 12×1630×0.75/1000 = 12.36 + 14.67 = 27.03 kW）
```

### 2.4 续航倍数解析界与质量律

同电量续航倍数有闭式解 E = P_base/P_悬停。代入分解式后可见两个结构性结论：其一，(1−s)^1.5 = 0.125（s 顶格时）给出理论上确界 **E → 1/0.125 = 8.0×**（场维持项归零端），实际被 12 W/kg 耗散稀释至 3.17~3.83；其二，**P_base ∝ m^1.2 使 m/P_base ∝ m^−0.2 单调递减 —— 质量越大，场维持项相对越小，E 越高**，这正是 pickup（×3.83）高于 sedan（×3.66）的解析来源，而非数值巧合：

```
E = P_base / P_悬停 = 1 / [ (1−s)^1.5 + 12·m·s / (1000·P_base) ]
P_base ∝ m^1.2 ⇒ m/P_base ∝ m^−0.2    （质量律：E 随整备质量单调上升）
s = 0.688（sport 未顶格）→ E = 1/(0.1744 + 0.1410) = 3.17    （恰为六车型最低，见第 06 章）
```

### 2.5 峰值因子的解析上界

「无明显能耗峰值」不是经验观察而是**可证的界**。起飞瞬间仅风扇推力 ×1.2（爬升余量），场份额不变，故峰值恒出现在起飞而非悬停。峰值因子是 P_fan 与 P_field 的加权平均：纯风扇端上确界为 1.2^1.5 = 1.3145，场维持项（不随风推力增长）把它稀释至 1.14~1.17 —— 这就是 1.25 限值留有余量的数学来源。转向差动仅 +5%，恒低于起飞增量：

```
P_takeoff = P_base·[1.2·(1−s)]^1.5 + P_field    （仅风扇 ×1.2，场份额不变）
峰值因子 = P_takeoff / P_悬停    （P_field→0 端上确界 1.2^1.5 = 1.3145；含场维持稀释至 1.14~1.17）
```

### 2.6 过阻尼回路、C² 剖面与延迟合成

姿态与运动学的三条判据同样解析可证。**过阻尼**：ζ = 1 + 0.6·η_cdm ≥ 1 使二阶姿态环零超调，时间常数 τ = 1000/(ζ·2π·f_n) = 63.7/ζ ms（f_n = 2.5 Hz）；8° 阵风回落至 ±2° 带内为单调指数衰减 t_rec = τ·ln(8/2) = 88.3/ζ ms（ζ = 1.12 → 78.8 ms）。**C² 剖面**：quintic s(u) = 6u⁵ − 15u⁴ + 10u³ 的端点速度与加速度同时归零 —— 三次曲线只能保 C¹，端点加速度跳变即冲击感；峰值斜率 1.875 给出 T = 1.875·|Δ|/45°/s。**延迟合成**：指令链路（感知 + 解算 + 场建立，30 + 6·n_fans ms）与恢复时间取大者：

```
ζ(η_cdm) = 1 + 0.6·η_cdm ≥ 1    （过阻尼 → 零超调 → 无眩晕数学保证）
τ = 1000/(ζ·2π·2.5) = 63.7/ζ ms；t_rec = τ·ln(8/2) = 88.3/ζ ms    （ζ=1.12 → 78.8 ms）
s(u) = 6u⁵ − 15u⁴ + 10u³，s′端点 = s″端点 = 0    （quintic C²；峰值斜率 1.875）
latency = max(30 + 6·n_fans, t_rec) ≤ 100 ms    （风扇 2~8、η_cdm 0~0.3 全参数范围核验）
```

> **理论链收束**：五项目标的全部判据最终归结为三个受界假设（η_e、η_cdm、盘载荷基准）与四组解析式（g_eff → s → P_悬停 → quintic/ζ）。正因为指标随参数**解析**响应，第 06 章「sport 未顶格 → 续航最低」的自洽证据与「η 归零 → 如实退化」的诚实性机制才得以成立 —— 它们不是被设计出来的表现，而是模型的数学必然。

## 03 目标一：悬停姿态偏差 ≤±2°

悬停姿态由**过阻尼二阶回路**保障：阻尼比 ζ = 1 + 0.6·η_cdm ≥ 1（暗物质惯性配比），控制带宽 f_n = 2.5 Hz，无超调振荡。稳态残余微摆采用双低频正弦谱（0.07 / 0.11 Hz），峰值 0.85°/ζ，两频率均远离 0.5~1 Hz 人体晕动敏感频段。

```
ζ = 1 + 0.6·η_cdm ≥ 1    （过阻尼 → 零超调）
θ(t) = (0.85/ζ)·[0.588·sin(2π·0.07t) + 0.412·sin(2π·0.11t + 1.3)]    （deg）
8° 阵风回落时间 = τ·ln(8/2)，τ = 1000/(ζ·2π·f_n)    （ζ=1.12 → 78.8 ms）
```

## 04 目标二：全自由度 360° 无限制原地转向

偏航指令采用**累计角无 wrap** 设计：连续指令多圈累加，理论上无圈数限制。转向剖面 Δ·quintic(t/T) 为 C² 连续曲线 —— 端点角速度与角加速度均为零，**无卡顿、无姿态失稳**；时长按峰值角速度 45°/s 舒适限动态计算（T = 1.875·|Δ|/45），360° 全周恰为 15.0 s。

```
T = 1.875·|Δ| / 45°/s    （1.875 为 quintic 中点峰值斜率；最短 2.5 s 过渡带）
ψ(t) = Δ·(6t⁵−15t⁴+10t³)/T⁵·…    （五次 smoothstep，C² 连续）
峰值角速度 = 1.875·Δ/T = 45°/s    （视场旋转晕动阈内）
```

## 05 垂直起降剖面：C² 平滑无眩晕

起升高度采用五次 smoothstep 曲线 h(t) = H·s(t/T)，**端点速度与加速度严格为零** —— 起飞与着陆瞬间无冲击感。配合三项无眩晕保证：悬浮呼吸振幅 <0.2% 车长（≤9.2 mm）、频率 <0.2 Hz、全程相机零滚转。

## 06 目标三 + 四：续航 ≥3× 与全工况无能耗峰值

### 6.1 能耗模型

反重力技术路线的核心节能逻辑：暗能量负压场是**度规效应（几何曲率）而非推进做功**，维持功率仅 12 W/kg 量级的相干性耗散；传统动力基准取同量级高效升力风扇盘载荷模型 P_base = 55 kW/t^1.2，风扇诱导功率随推力 1.5 次方缩减。

```
场升力份额 s = 2.6·η_e + 1.8·η_cdm ≤ 0.75    （风扇保留 ≥25% 做姿态差动）
P_悬停 = P_base·(1−s)^1.5 + 12 W/kg·m·s    （风扇 + 场维持）
E = P_base / P_悬停 ≥ 3    （同电量续航倍数，六车型预设达标）
```

## 07 目标五：飞控响应延迟 ≤100ms

响应延迟取两条链路的较大者：**指令链路延迟**（感知 + 解算 + 场建立，30 ms 基座 + 每风扇差动通道 6 ms）与**大扰动恢复时间**（8° 阵风回落至 ±2° 带内，ζ≥1 单调无超调指数衰减 τ·ln4）。

全参数范围核验：风扇 2~8、η_cdm 0~0.3 的 16 组组合下延迟均 ≤100 ms（vitest 断言锁定）。飞行动作切换（起飞 ↔ 悬停 ↔ 转向 ↔ 降落）复用同一 C² 剖面机制，切换指令即改变剖面目标，**无独立切换延迟**。

## 10 结论、边界与后续

### 10.1 结论

- **五项技术目标全部达标且留有设计余量**：姿态 ±0.76°（余量 2.6×）、360° 转向 15.0 s（45°/s 舒适限）、续航 ×3.17~3.83（最低项余量 5.7%）、峰值因子 ×1.14~1.17（限值 1.25）、延迟 76~80 ms（余量 ≥20 ms）。
- **最优平衡的实现路径**：以「场份额顶格 + 风扇差动保底」的分工承接反重力科幻叙事，以 C² 五次 smoothstep 统一起升/转向/降落三类运动剖面，以过阻尼 ζ≥1 与低频谱约束锁死晕动风险 —— 算法（C² 剖面）、物理（度规效应类比）、数学（受界钳位）、航天（推重比充要）与体验（无眩晕三重保证）五线收敛于同一组可复现公式。
- **模型诚实性**：参数→性能响应物理自洽（sport 场份额未顶格→续航最低；η 归零→如实退化不达标），全部判定可被用户在 UI 上实时复现与推翻。

### 10.2 边界

- 本报告数据为**设计仿真平台的工程估算模型**输出：能耗基准（55 kW/t^1.2）、场维持比功率（12 W/kg）、整车密度（120 kg/m³）为模型假设，非真机测量；
- 暗能量/暗物质参数为「科幻受界」类比叙事（η∈[0,0.3]），物理上对应度规效应/惯性屏蔽的工程化抽象；
- 「实测」一词在本报告中指：**部署产物的实时计算读数**经公网环境核验，而非风洞/试飞级测量。

### 10.3 后续

- 引入阵风谱时域仿真（Dryden 模型）替代单点 8° 注入，细化姿态恢复时间分布；
- 能耗模型接入电池放电倍率约束，输出真实续航-功率包络曲面；
- 多车编队悬浮的场干涉分析与无眩晕相机跟随策略。
