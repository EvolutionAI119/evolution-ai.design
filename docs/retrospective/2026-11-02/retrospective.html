这套方法不是口号，而是已经固化成机制：世界模型 = 单一真源参数世界；自迭代 = 记忆→约束→技能；持续优化 = 性能/体积/载荷/启动。

原则落地机制证据
世界模型22 维 CarParams + 六车型比例表 + 轮拱包络 + 内饰锚点；所有视图都是同一模型的投影carProfile / carInteriorLayout 单一真源
预测—验证—修正先写纯函数与断言（预测），再跑测试/多机位（观测），偏差回写记忆（修正）771 前端断言；FIX-01~FIX-12
自迭代踩坑沉淀为 project_memory 硬约束；事故升级为 skill206 行项目记忆；7 个仓库技能
持续优化Cython 70×/34×；chunk 拆分；JSON 200KB 守卫；生产 fail-fast记忆条目 + 架构文档
证据型交付数字必须带命令+日期+SHA；发布必须公网 MD5 比对VALIDATION_REPORT + deploy-gh-pages
