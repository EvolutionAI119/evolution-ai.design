## 2. 座椅安装基准坐标校准记录（R-01/R-02 专项）

### 2.1 校准方法

按整改要求对六车型前排座椅安装基准进行**重新采集与复核**：

1. 以门洞分缝为锚点重新采集前门洞前缘 X（`deriveDoorAperturesX`，与外观 `deriveDoorLayout` 同源）；
2. 复核 H 点 = min（门洞锚点， 仪表台膝部封顶）——推导证明 H 基准本身正确，**干涉根因在滑轨行程参数而非基准坐标**，故 H 点维持门洞锚定值不偏移（偏移会破坏 entry ≥ 160mm 或使 coupe/sport 膝部恶化）；
3. 修正项 = **座椅定位参数（滑轨有效行程）**：设计位不变，前/后向行程按障碍余量收窄（软限位，与实车行程限位器逻辑一致）；
4. 调角器限位角按「滑轨最后端」worst case 重新标定（实车机械限位必须覆盖最恶劣工况）。

## 3. 补充的运动学仿真模型（R-04 交付）

### 3.1 模型参数表（实车对标，`KINEMATICS_PARAMS`）

| 部件 | 参数 | 取值 | 实车依据 |
|---|---|---|---|
| 调角器 | 旋转中心 / 前倒行程 / 后倒行程 / 扫掠步长 | H 点 / 0.10rad(≈5.7°) / 0.20rad(≈11.5°) / 0.01rad | 实车调角器典型行程 ±5°~12° |
| 遮阳板 | 展长 / 铰链下沉 / 扫掠域 / 步长 | 190mm / 35mm（顶棚内表面下）/ 0~180° / 5° | 实车遮阳板 180~200mm |
| 扶手盖 | 有效盖长 / 开启上限 / 铰链 / 步长 | ≤320mm（取 min(320, 中控长×0.6)=240mm）/ 75°(1.31rad) / 中控台后端顶面 / 0.05rad | 实车扶手盖 280~340mm、开启 70~80° |
| 公共 | 端点安全余量 | 10mm（与 `INTERIOR_GEOM.seatTravelMargin` 同源） | 布置冻结阈值 |

### 3.2 运动轨迹逻辑

- **调角器**：靠背绕 H 点在 [设计角−5.7°, 设计角+11.5°] 逐角扫掠；障碍 = 前排 B 柱前缘（按滑轨最后端 worst case）/ 中排下一排坐垫前缘 / 末排座舱后界；自动求**限位角**（间隙跌破 10mm 前的最后安全角）。
- **遮阳板**：绕顶棚前缘铰链自「贴顶棚收纳」向前翻转；板尖触及风挡玻璃即限位（接触角 = 有效翻转上限，其后行程物理不可达）；全程不得穿透顶棚内表面。
- **扶手盖**：绕中控台后端铰链 0→75°；Z 向随中央通道（与前排座椅错层）；盖尖全程不得进入仪表台 AABB。

## 4. 更新后的全行程干涉检查报告（整改后复跑）

覆盖范围：**全部运动部件全使用行程** = 滑轨前/后端点 × 调角器全行程（滑轨最后端 worst case）× 遮阳板 0→接触角 × 扶手盖 0→75°，六车型全量。

| 运动件 | 行程端点/全程 | sedan | suv | coupe | sport | mpv | pickup | 结论 |
|---|---|---|---|---|---|---|---|---|
| 滑轨 | 最前端（膝部↔IP） | +84.2 | +135.3 | **+10.0** | **+10.0** | +215.3 | +62.4 | ✅ 无干涉 |
| 滑轨 | 最后端（靠背↔B 柱） | **+10.0** | **+10.0** | +222.0 | +106.5 | +48.9 | +1121.5 | ✅ 无干涉 |
| 调角器 | 全行程（限位后最小间隙） | +10.0 | +10.0 | +125.8 | +8.6→限位后 +13.2 | +10.1 | +1028.4 | ✅ 无干涉 |
